¿Qué es JavaScript?

🌐

Lenguaje de Programación Web

JavaScript es un lenguaje de programación interpretado, dinámico y multi-paradigma que se ejecuta en navegadores y servidores.

⚡

Para Qué Sirve

Desarrollo web frontend, backend con Node.js, aplicaciones móviles, desktop, inteligencia artificial y más.

🔧

Características Principales

Tipado dinámico, orientado a prototipos, funcional, asíncrono, single-threaded con event loop y no bloqueante.

💡 ¿Sabías qué?

JavaScript fue creado en solo 10 días por Brendan Eich en 1995 para Netscape. A pesar del nombre, no tiene relación con Java. Es el lenguaje más usado en el mundo según Stack Overflow.

Arquitectura de JavaScript

JavaScript utiliza un modelo de ejecución single-threaded con event loop para manejar operaciones asíncronas.

Variables y Tipos de Datos

Las variables son contenedores para almacenar datos. JavaScript ofrece tres formas de declarar variables: var, let y const.

Declaración de Variables

// var - alcance de función (legacy)
var nombre = "Juan";

// let - alcance de bloque, reasignable
let edad = 25;
edad = 26; // válido

// const - alcance de bloque, no reasignable
const PI = 3.1416;
// PI = 3.14; // ERROR!

Tipos de Datos Primitivos

String

Cadenas de texto entre comillas

let nombre = "María";

Number

Números enteros y decimales

let edad = 30;

Boolean

Valores verdadero o falso

let activo = true;

Null

Valor nulo intencional

let dato = null;

Undefined

Variable sin valor asignado

let x; // undefined

Symbol

Identificador único

let id = Symbol("id");

Ejemplo Práctico

// Declaración y uso de variables
const usuario = {
    nombre: "Carlos",
    edad: 28,
    esActivo: true
};

let contador = 0;
contador = contador + 1;

console.log(`Hola, ${usuario.nombre}`);
console.log(`Tipo de dato: ${typeof usuario.edad}`);
💡 Consejo: Usa const por defecto y solo usa let cuando necesites reasignar la variable. Evita var en código moderno.

Operadores y Expresiones

Los operadores permiten realizar operaciones con valores y variables. JavaScript incluye diversos tipos de operadores.

Operadores Aritméticos

let a = 10, b = 3;

a + b   // 13 - Suma
a - b   // 7  - Resta
a * b   // 30 - Multiplicación
a / b   // 3.33 - División
a % b   // 1  - Módulo (resto)
a ** b  // 1000 - Potencia
a++     // 11 - Incremento
b--     // 2  - Decremento

Operadores de Comparación

5 == "5"   // true - Igualdad (con conversión)
5 === "5"  // false - Igualdad estricta
5 != "5"   // false - Desigualdad
5 !== "5"  // true - Desigualdad estricta
5 > 3      // true - Mayor que
5 < 3      // false - Menor que
5 >= 5     // true - Mayor o igual
5 <= 5     // true - Menor o igual

Operadores Lógicos

true && false  // false - AND (y)
true || false  // true  - OR (o)
!true          // false - NOT (no)

// Short-circuit evaluation
let nombre = usuario?.nombre || "Anónimo";
let activo = esUsuario && tienePermiso;

Operadores de Asignación

let x = 10;
x += 5;  // x = x + 5 → 15
x -= 3;  // x = x - 3 → 12
x *= 2;  // x = x * 2 → 24
x /= 4;  // x = x / 4 → 6
x %= 4;  // x = x % 4 → 2
💡 Consejo: Siempre usa === y !== en lugar de == y != para evitar conversiones de tipo inesperadas.

Estructuras de Control

Las estructuras de control permiten alterar el flujo de ejecución del programa según condiciones específicas.

Condicionales: if/else

const edad = 18;

if (edad >= 18) {
    console.log("Es mayor de edad");
} else if (edad >= 13) {
    console.log("Es adolescente");
} else {
    console.log("Es niño");
}

// Ternario
const estado = edad >= 18 ? "adulto" : "menor";

Switch

const dia = 3;
let nombreDia;

switch (dia) {
    case 1:
        nombreDia = "Lunes";
        break;
    case 2:
        nombreDia = "Martes";
        break;
    case 3:
        nombreDia = "Miércoles";
        break;
    default:
        nombreDia = "Día inválido";
}

// Switch moderno con múltiples casos
switch (fruta) {
    case "manzana":
    case "pera":
        console.log("Fruta de árbol");
        break;
}

Bucles: for

// For tradicional
for (let i = 0; i < 5; i++) {
    console.log(i); // 0, 1, 2, 3, 4
}

// For...of (arrays)
const colores = ["rojo", "verde", "azul"];
for (const color of colores) {
    console.log(color);
}

// For...in (objetos)
const persona = { nombre: "Ana", edad: 30 };
for (const clave in persona) {
    console.log(`${clave}: ${persona[clave]}`);
}

Bucles: while y do...while

// While - verifica antes
let i = 0;
while (i < 5) {
    console.log(i);
    i++;
}

// Do...while - ejecuta al menos una vez
let j = 0;
do {
    console.log(j);
    j++;
} while (j < 5);
💡 Consejo: Usa for...of para iterar arrays y for...in solo para objetos. Evita for...in con arrays.

Funciones

Las funciones son bloques de código reutilizables que realizan una tarea específica. Son fundamentales en JavaScript.

Declaración de Funciones

// Function declaration (hoisting)
function saludar(nombre) {
    return `Hola, ${nombre}!`;
}

// Function expression
const despedir = function(nombre) {
    return `Adiós, ${nombre}!`;
};

// Arrow function (ES6)
const sumar = (a, b) => a + b;

// Arrow con múltiples líneas
const calcularTotal = (precio, impuesto) => {
    const subtotal = precio * impuesto;
    return precio + subtotal;
};

Parámetros y Argumentos

// Parámetros por defecto
function saludar(nombre = "Invitado") {
    return `Hola, ${nombre}!`;
}

// Rest parameters
function sumar(...numeros) {
    return numeros.reduce((acc, num) => acc + num, 0);
}
sumar(1, 2, 3, 4); // 10

// Destructuring en parámetros
function mostrarUsuario({ nombre, edad }) {
    console.log(`${nombre} tiene ${edad} años`);
}

Funciones de Orden Superior

// Función que retorna otra función
function crearMultiplicador(multiplicador) {
    return function(numero) {
        return numero * multiplicador;
    };
}

const duplicar = crearMultiplicador(2);
duplicar(5); // 10

// Callback function
function procesarDatos(datos, callback) {
    const resultado = datos.toUpperCase();
    callback(resultado);
}

procesarDatos("hola", console.log); // "HOLA"

IIFE (Immediately Invoked Function Expression)

// IIFE tradicional
(function() {
    const privado = "valor";
    console.log(privado);
})();

// IIFE con arrow function
(() => {
    console.log("Ejecutado inmediatamente");
})();
💡 Consejo: Las arrow functions no tienen su propio this, lo que las hace ideales para callbacks pero no para métodos de objetos.

Arrays y Métodos

Los arrays son colecciones ordenadas de valores. JavaScript ofrece métodos poderosos para manipularlos.

Creación y Acceso

// Creación de arrays
const numeros = [1, 2, 3, 4, 5];
const mixto = [1, "hola", true, null];
const vacio = [];

// Acceso a elementos
numeros[0];     // 1
numeros[-1];    // undefined
numeros.length; // 5

// Destructuring
const [primero, segundo, ...resto] = numeros;
// primero = 1, segundo = 2, resto = [3, 4, 5]

Métodos de Transformación

const numeros = [1, 2, 3, 4, 5];

// map - transforma cada elemento
const dobles = numeros.map(n => n * 2);
// [2, 4, 6, 8, 10]

// filter - filtra elementos
const pares = numeros.filter(n => n % 2 === 0);
// [2, 4]

// reduce - reduce a un valor
const suma = numeros.reduce((acc, n) => acc + n, 0);
// 15

Métodos de Búsqueda

const usuarios = [
    { id: 1, nombre: "Ana" },
    { id: 2, nombre: "Luis" },
    { id: 3, nombre: "Carlos" }
];

// find - encuentra el primer elemento
const usuario = usuarios.find(u => u.id === 2);

// findIndex - encuentra el índice
const indice = usuarios.findIndex(u => u.nombre === "Luis");

// some - verifica si alguno cumple
const hayAdmin = usuarios.some(u => u.rol === "admin");

// every - verifica si todos cumplen
const todosActivos = usuarios.every(u => u.activo);

Métodos de Manipulación

const arr = [1, 2, 3];

// Agregar elementos
arr.push(4);        // [1, 2, 3, 4] - al final
arr.unshift(0);     // [0, 1, 2, 3, 4] - al inicio

// Eliminar elementos
arr.pop();          // elimina último
arr.shift();        // elimina primero

// slice vs splice
const original = [1, 2, 3, 4, 5];
const copia = original.slice(1, 3);  // [2, 3] - no muta
original.splice(1, 2, "a", "b");     // muta el original
💡 Consejo: Prefiere métodos que no mutan el array original (map, filter, slice) para mantener la inmutabilidad y evitar efectos secundarios.

Objetos y Prototipos

Los objetos son colecciones de pares clave-valor. JavaScript está basado en prototipos, no en clases tradicionales.

Creación de Objetos

// Object literal
const persona = {
    nombre: "Juan",
    edad: 30,
    saludar() {
        return `Hola, soy ${this.nombre}`;
    }
};

// Constructor function
function Persona(nombre, edad) {
    this.nombre = nombre;
    this.edad = edad;
}

const juan = new Persona("Juan", 30);

// Object.create
const proto = { saludar() { return "Hola"; } };
const obj = Object.create(proto);

Acceso y Manipulación

const usuario = {
    nombre: "María",
    edad: 25,
    direccion: { ciudad: "Madrid" }
};

// Notación de punto
usuario.nombre; // "María"

// Notación de corchete
usuario["edad"]; // 25
const clave = "nombre";
usuario[clave]; // "María"

// Destructuring
const { nombre, edad } = usuario;

// Spread operator
const nuevo = { ...usuario, pais: "España" };

Prototype Chain

function Animal(nombre) {
    this.nombre = nombre;
}

Animal.prototype.hablar = function() {
    return `${this.nombre} hace un sonido`;
};

function Perro(nombre, raza) {
    Animal.call(this, nombre);
    this.raza = raza;
}

// Herencia prototípica
Perro.prototype = Object.create(Animal.prototype);
Perro.prototype.constructor = Perro;

Perro.prototype.ladrar = function() {
    return `${this.nombre} ladra`;
};

const firulais = new Perro("Firulais", "Labrador");
firulais.hablar(); // "Firulais hace un sonido"

Métodos de Objetos

const obj = { a: 1, b: 2, c: 3 };

// Obtener claves, valores, entradas
Object.keys(obj);    // ["a", "b", "c"]
Object.values(obj);  // [1, 2, 3]
Object.entries(obj); // [["a",1], ["b",2], ["c",3]]

// Asignar propiedades
Object.assign({}, obj, { d: 4 });

// Congelar y sellar
Object.freeze(obj);  // inmutable
Object.seal(obj);    // no agregar/eliminar
💡 Consejo: Entiende la cadena de prototipos para dominar JavaScript. Las clases ES6 son azúcar sintáctico sobre el sistema de prototipos.

DOM Manipulation

El Document Object Model (DOM) es la representación en árbol del HTML. JavaScript permite manipularlo dinámicamente.

Selección de Elementos

// Métodos tradicionales
document.getElementById("miId");
document.getElementsByClassName("miClase");
document.getElementsByTagName("div");

// Métodos modernos (recomendados)
document.querySelector("#miId");
document.querySelector(".miClase");
document.querySelectorAll("div.item");

// Selección del body y document
document.body;
document.documentElement;

Manipulación de Contenido

const elemento = document.querySelector("#titulo");

// Leer contenido
elemento.textContent;     // Solo texto
elemento.innerHTML;       // HTML incluido
elemento.innerText;       // Texto renderizado

// Modificar contenido
elemento.textContent = "Nuevo título";
elemento.innerHTML = "HTML";

// Crear elementos
const nuevoDiv = document.createElement("div");
nuevoDiv.className = "mi-clase";
nuevoDiv.textContent = "Contenido";

// Agregar al DOM
document.body.appendChild(nuevoDiv);
elemento.prepend(nuevoDiv);  // al inicio

Manipulación de Clases y Atributos

const btn = document.querySelector("#miBoton");

// Clases (classList API)
btn.classList.add("activo");
btn.classList.remove("oculto");
btn.classList.toggle("dark");
btn.classList.contains("activo"); // true/false

// Atributos
btn.getAttribute("href");
btn.setAttribute("href", "#nuevo");
btn.removeAttribute("target");

// Data attributes
btn.dataset.id = "123";
const id = btn.dataset.id;

Estilos y Dimensiones

const caja = document.querySelector(".caja");

// Estilos inline
caja.style.color = "red";
caja.style.backgroundColor = "#000";
caja.style.cssText = "color: blue; padding: 10px;";

// Dimensiones
caja.offsetWidth;    // ancho con padding
caja.offsetHeight;   // alto con padding
caja.getBoundingClientRect(); // posición y tamaño

// Scroll
window.scroll(0, 100);
elemento.scrollIntoView();
💡 Consejo: Usa classList en lugar de manipular className directamente. Es más legible y menos propenso a errores.

Eventos del Navegador

Los eventos son acciones que ocurren en el navegador. JavaScript permite escuchar y responder a estos eventos.

Event Listeners

const boton = document.querySelector("#miBoton");

// addEventListener (recomendado)
boton.addEventListener("click", function(e) {
    console.log("Click!", e);
});

// Arrow function
boton.addEventListener("click", (e) => {
    e.preventDefault();
    console.log(this); // cuidado con el contexto
});

// Múltiples eventos
["click", "dblclick", "contextmenu"].forEach(evento => {
    boton.addEventListener(evento, manejarEvento);
});

// Remover listener
function handler() { /* ... */ }
boton.addEventListener("click", handler);
boton.removeEventListener("click", handler);

Tipos de Eventos

// Mouse events
elemento.addEventListener("click", handler);
elemento.addEventListener("dblclick", handler);
elemento.addEventListener("mousedown", handler);
elemento.addEventListener("mouseup", handler);
elemento.addEventListener("mousemove", handler);
elemento.addEventListener("mouseenter", handler);
elemento.addEventListener("mouseleave", handler);

// Keyboard events
document.addEventListener("keydown", handler);
document.addEventListener("keyup", handler);
document.addEventListener("keypress", handler);

// Form events
formulario.addEventListener("submit", handler);
input.addEventListener("change", handler);
input.addEventListener("input", handler);
input.addEventListener("focus", handler);
input.addEventListener("blur", handler);

Event Object

elemento.addEventListener("click", function(e) {
    // Propiedades del evento
    e.target;        // elemento que disparó
    e.currentTarget; // elemento con listener
    e.type;          // tipo de evento
    e.timeStamp;     // timestamp
    
    // Mouse events
    e.clientX;       // posición X
    e.clientY;       // posición Y
    e.button;        // botón presionado
    
    // Keyboard events
    e.key;           // tecla presionada
    e.code;          // código de tecla
    e.ctrlKey;       // Ctrl presionado
    
    // Métodos
    e.preventDefault();  // evita comportamiento default
    e.stopPropagation(); // detiene propagación
});

// En lugar de agregar listeners a cada item
const lista = document.querySelector("#miLista");

lista.addEventListener("click", function(e) {

    }
    if (e.target.closest(".item")) {
        const item = e.target.closest(".item");
        console.log("Item:", item.textContent);
    }
});

// Ventaja: funciona con elementos dinámicos
lista.innerHTML += '
  • Nuevo
    • ';
    💡 Consejo: Usa event delegation para listas grandes o elementos dinámicos. Mejora el rendimiento y evita agregar/remover listeners constantemente.

    Programación Asíncrona

    JavaScript es single-threaded pero puede manejar operaciones asíncronas mediante callbacks, promesas y async/await.

    Callbacks

    // Callback tradicional
function procesarDatos(datos, callback) {
    setTimeout(() => {
        const resultado = datos.toUpperCase();
        callback(resultado);
    }, 1000);
}

procesarDatos("hola", (resultado) => {
    console.log(resultado); // "HOLA"
});

// Callback hell (evitar)
obtenerUsuario((usuario) => {
    obtenerPosts(usuario.id, (posts) => {
        obtenerComentarios(posts[0].id, (comentarios) => {
            console.log(comentarios);
        });
    });
});

    Promesas

    // Crear promesa
const promesa = new Promise((resolve, reject) => {
    setTimeout(() => {
        const exito = true;
        if (exito) {
            resolve("Datos obtenidos");
        } else {
            reject("Error en la solicitud");
        }
    }, 1000);
});

// Consumir promesa
promesa
    .then(resultado => console.log(resultado))
    .catch(error => console.error(error))
    .finally(() => console.log("Finalizado"));

// Encadenamiento
obtenerUsuario()
    .then(usuario => obtenerPosts(usuario.id))
    .then(posts => obtenerComentarios(posts[0].id))
    .then(comentarios => console.log(comentarios));

    Async/Await

    // Función async
async function obtenerDatos() {
    try {
        const usuario = await obtenerUsuario();
        const posts = await obtenerPosts(usuario.id);
        const comentarios = await obtenerComentarios(posts[0].id);
        return comentarios;
    } catch (error) {
        console.error("Error:", error);
        throw error;
    }
}

// Múltiples promesas en paralelo
async function obtenerTodo() {
    const [usuarios, posts, comentarios] = await Promise.all([
        obtenerUsuarios(),
        obtenerPosts(),
        obtenerComentarios()
    ]);
    return { usuarios, posts, comentarios };
}

    Fetch API

    // GET request
async function obtenerDatos() {
    const response = await fetch("/api/usuarios");
    const datos = await response.json();
    return datos;
}

// POST request
async function crearUsuario(usuario) {
    const response = await fetch("/api/usuarios", {
        method: "POST",
        headers: {
            "Content-Type": "application/json"
        },
        body: JSON.stringify(usuario)
    });
    return await response.json();
}

// Manejo de errores
try {
    const response = await fetch("/api/datos");
    if (!response.ok) {
        throw new Error(`HTTP ${response.status}`);
    }
    const datos = await response.json();
} catch (error) {
    console.error("Fetch error:", error);
}
    💡 Consejo: Usa async/await para código más limpio y legible. Usa Promise.all() para ejecutar promesas en paralelo cuando no haya dependencias.

    Módulos ES6

    Los módulos permiten dividir el código en archivos separados y reutilizables. ES6 introdujo un sistema de módulos nativo.

    Exportar

    // math.js

// Export named
export const PI = 3.1416;
export function sumar(a, b) {
    return a + b;
}
export class Calculadora {
    // ...
}

// Export default (uno por archivo)
export default function calcular() {
    // ...
}

// Exportar al final
const VERSION = "1.0.0";
export { VERSION, sumar, PI };

    Importar

    // Import named exports
import { sumar, PI } from "./math.js";
import { sumar as add, PI } from "./math.js";

// Import default
import calcular from "./math.js";

// Import todo como namespace
import * as MathUtils from "./math.js";
MathUtils.sumar(1, 2);

// Import side effects (sin bindings)
import "./styles.css";
import "./polyfills.js";

// Dynamic import (code splitting)
button.addEventListener("click", async () => {
    const modulo = await import("./modulo.js");
    modulo.funcion();
});

    Uso en HTML

    <!-- En HTML -->
<script type="module" src="main.js"></script>

<!-- Con defer (recomendado) -->
<script type="module" src="main.js" defer></script>

<!-- Import map para aliases -->
<script type="importmap">
{
    "imports": {
        "lodash": "https://cdn.skypack.dev/lodash",
        "utils/": "./src/utils/"
    }
}
</script>

    Patrones Comunes

    // Barrel export (index.js)
export { default as Usuario } from "./Usuario.js";
export { default as Producto } from "./Producto.js";
export * from "./constants.js";

// Re-export
export { sumar, restar } from "./math.js";
export * from "./utils.js";

// Conditional loading
if (condition) {
    const modulo = await import("./moduloA.js");
} else {
    const modulo = await import("./moduloB.js");
}
    💡 Consejo: Usa exports named por defecto y default solo cuando el módulo tenga una única responsabilidad clara. Facilita el tree-shaking.

    Clases y Herencia

    Las clases ES6 son azúcar sintáctico sobre el sistema de prototipos. Proporcionan una sintaxis más clara para la herencia.

    Declaración de Clases

    class Persona {
    // Constructor
    constructor(nombre, edad) {
        this.nombre = nombre;
        this.edad = edad;
    }

    // Método de instancia
    saludar() {
        return `Hola, soy ${this.nombre}`;
    }

    // Getter
    get info() {
        return `${this.nombre}, ${this.edad} años`;
    }

    // Setter
    set edad(valor) {
        if (valor < 0) throw new Error("Edad inválida");

    Herencia con Extends

    class Empleado extends Persona {
    constructor(nombre, edad, puesto) {
        super(nombre, edad); // llama al constructor padre
        this.puesto = puesto;
        this.salario = 0;
    }

    // Sobrescribir método
    saludar() {
        return `${super.saludar()}, soy ${this.puesto}`;
    }

    // Nuevo método
    trabajar() {
        return `${this.nombre} está trabajando como ${this.puesto}`;
    }
}

const emp = new Empleado("Juan", 30, "Desarrollador");

    Propiedades Privadas

    class CuentaBancaria {
    // Propiedad privada (ES2022)
    #saldo = 0;
    #pin;

    constructor(pin) {
        this.#pin = pin;
    }

    depositar(cantidad) {
        if (cantidad > 0) {
            this.#saldo += cantidad;
        }
    }

    retirar(cantidad, pin) {
        if (pin !== this.#pin) {
            throw new Error("PIN incorrecto");
        }
        if (cantidad > this.#saldo) {
            throw new Error("Saldo insuficiente");
        }
        this.#saldo -= cantidad;
    }

    get saldo() {
        return this.#saldo;
    }
}

    Patrones y Buenas Prácticas

    Los patrones de diseño y buenas prácticas ayudan a escribir código más limpio, mantenible y eficiente.

    Closures

    // Closure básico
function crearContador() {
    let cuenta = 0;
    return function() {
        cuenta++;
        return cuenta;
    };
}

const contador = crearContador();
contador(); // 1
contador(); // 2

// Closure con factory
function crearSaludo(saludo) {
    return function(nombre) {
        return `${saludo}, ${nombre}!`;
    };
}

const saludar = crearSaludo("Hola");
const despedir = crearSaludo("Adiós");
saludar("Juan"); // "Hola, Juan!"

    Spread y Rest

    // Spread operator
const arr1 = [1, 2, 3];
const arr2 = [...arr1, 4, 5, 6];

const obj1 = { a: 1, b: 2 };

    return numeros.reduce((a, b) => a + b, 0);

    Patrones Comunes

    // Module Pattern
const MiModulo = (function() {
    let privado = 0;
    return {
        incrementar() { privado++; },
        obtener() { return privado; }
    };
})();

// Singleton
class Singleton {
    static instancia;
    static obtenerInstancia() {
        if (!Singleton.instancia) {
            Singleton.instancia = new Singleton();
        }
        return Singleton.instancia;
    }
}

// Observer Pattern
class EventEmitter {
    constructor() {
        this.eventos = {};
    }
    on(evento, callback) {
        if (!this.eventos[evento]) {
            this.eventos[evento] = [];
        }
        this.eventos[evento].push(callback);
    }
    emit(evento, datos) {
        this.eventos[evento]?.forEach(cb => cb(datos));
    }
}
